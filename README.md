# 室內設計 3D：最新圖面 r02

主要維護 repo：`pc007ya/floorplan-3d`，分支 `master`。網站：https://pc007ya.github.io/floorplan-3d/

模型依最新建築圖向量及水電客變註記更新。圖面 1:100 比例以 750 mm 與 825 mm 標示交叉核對，仍不是現場實測、施工圖或結構判定。原始 PDF、照片、地址、案名、戶別和個人識別資訊不存入公開 repo。

## 本次同步

- 11 個區域、43 段牆／柱、4 處窗、7 個原門洞記錄、2 處陽台落地門、27 件家具／設備提案
- 沙發座面朝向電視；只調整方向，保留位置與尺寸
- 主臥至宜居陽台、下方臥室至工作陽台：開口沿用圖面寬度，地坪與軌道齊平，滑門展示開啟
- 客浴設備、門框門扇、鏡及淋浴依圖面取消；保留 750×2100 mm 無門洞口
- V2.3 外觀提案只套用主浴 A 與次浴 B；可切換暖米／冷灰、關閉外觀及隔間
- TV 螢幕與機殼前移 45 mm 避免石材遮挡，電視櫃位置不變

兩處陽台門型、2400 mm 頂高、牆高及其他門窗高度仍為建模假設。圖面標註為結構尺寸，不能直接當成裝修淨尺寸。上方交叉線未標示區不生成可使用地坪。

## 使用與開發

公開網站與離線單檔均包含完整渲染依賴。可旋轉、縮放、剖切、2D／3D 切換、漫遊及編輯／保存家具方案。新版以不同本機儲存版本載入，避免舊座標家具覆蓋最新幾何。

原始開發介面：`python3 -m http.server 8000` 後開啟 `http://localhost:8000`。客浴圖示洞口可另輸入實測寬度校正比例；校正不等於所有尺寸均已驗收。

- `data/home.json`：去識別化圖面幾何、比例、取消清單、提案、待確認項目
- `engine.html`：完整保留原引擎，固定 blob `4cee1eae0684acfc660a27b18c218f1f7703193b`
- `js/compile-home.mjs`、`js/latest-geometry.mjs`：資料及幾何轉接，保留編輯／渲染功能
- `js/bathrooms-v23.mjs`：可關閉的 A／B 衛浴造型
- `node --test tests/*.test.mjs`：資料、尺寸、取消清單與轉接器測試

GitHub Actions 執行資料測試、Chromium WebGL、離線、衛浴與專案子路徑測試，再發布同一份驗證過的 artifact。以 CI 結果、公開 `build-info.json` 及實際頁面資料確認發布；工作流程存在不代表已成功。詳見 `docs/publishing.md`。

公開網站任何取得網址的人均可閱讀和保存模型。robots/noindex 不等於私人存取控制。日照模式僅為示意；拆牆與結構判定維持鎖定。
