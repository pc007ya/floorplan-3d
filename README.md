# 室內設計 3D：使用者圖面草模

主要維護 repo：`pc007ya/floorplan-3d`，分支 `master`。後續修改提交此 repo；不直接修改原作者 repo。

這是根據 IMG_6047.png（變更後建築圖）人工描繪的比例模型，並以 IMG_6049.png（水電無變更）比對。**不是實測模型、施工圖或結構判定**。原始圖面、識別欄位及地址不存入公開 repo。

## 使用

在 repo 根目錄執行 `python3 -m http.server 8000`，瀏覽 `http://localhost:8000`。預設載入自己的戶型，而非上游示範。首次開啟 3D 需要網路載入固定版本 Three.js r160。

可以旋轉、縮放、剖切、2D／3D 切換、進入漫遊、編輯家具、匯出圖片及家具方案 JSON。頁首「匯出 3D 網頁」輸出包含目前建模資料的單一 HTML（仍使用 CDN）；家具編輯的保存與匯出請使用內部編輯器的檔案選單。

**比例尚未校正。** 預設每描圖座標單位 12.5 mm 只是讓模型能先瀏覽，不能拿來採購或施工。輸入「下方兩根紅色柱符號中心距」可校正全圖比例，層高暫設 2800 mm。切換比例／層高採用不同本機儲存版本；既有家具布置不會自動搬移，請先匯出保存。

## 已建立

11 個區域、33 段牆／柱、6 處暫定窗開口、7 個門洞、11 件圖上可辨識的廚衛／長櫃示意物。房間 A／B／C 未命名成主臥、兒童房等；沒有擅自加入床、沙發。上側不規則範圍僅作外部情境區，不計入室內面積。地磚顏色／尺寸與設備高度均為示意。拆牆功能鎖定，示範造價已移除。

## 開發結構

- `data/home.json`：可追溯的描圖座標、房間、牆、門窗、固定設備、比例與待確認事項。
- `engine.html`：完整保留 wy51ai/floorplan-3d 上游原始引擎，不是本戶型的交付頁面。
- `js/compile-home.mjs`：固定版本的資料轉接器，保留原引擎的編輯／渲染功能；找不到預期程式位置時明確報錯，不退回示範戶型。
- `index.html`：校正介面，將本戶型資料套入引擎。
- `scripts/build.mjs`、`tests/`：編譯與檢查。`node --test tests/*.test.mjs`。
- `UPSTREAM.md`：原專案說明與功能來源。

引擎固定 blob：`4cee1eae0684acfc660a27b18c218f1f7703193b`。此版本採資料轉接，尚未將原引擎所有家具程式拆成模組。

GitHub Actions 執行 Node 測試與真實 Chromium WebGL smoke test，提供 `home-3d-build-and-verification` artifact。artifact 的 `dist/` 附固定 Three.js 依賴；在該資料夾啟動靜態伺服器即可不經外部 CDN 瀏覽。請以 Actions 實際結果判斷測試狀態；工作流程存在不代表已通過。尚未啟用 GitHub Pages 或公開網站部署。
