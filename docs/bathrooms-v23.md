# V2.3 衛浴試配｜實作與驗收

## 使用

repo 首頁及離線包都經 `js/compile-scene.mjs` 載入 V2.3。頂部的「衛浴 A／B／C」進入室內視角，「浴櫃近看」查看面盆與鏡面。「暖米石紋／冷灰石紋」只改目前選定衛浴。「隔間提案」可整組關閉；「玻璃門開／關」切換目前衛浴滑門位置；「衛浴外觀開／關」回復基礎模型；「全屋」恢復剖切。

本輪是示意建模，不是量測或施工復原。A 預設暖米、B 預設冷灰、C 預設暖米均為可逆試配，不表示房名或材質已獲實際確認。

## 已實作內容

- 程序生成的米色橫向石紋／灰色石紋牆面及深灰地磚。只覆蓋已知牆體靠衛浴的那一面；門洞低於門頭及窗洞保持開放。不是把整張照片貼到模型。
- `basin-a/b/c` 保留 id、位置、旋轉與平面尺寸，替換為分件櫃身、門片、檯面、中空面盆、排水件、銀色龍頭、鏡框與鏡面。
- `tub` 保留錨點與平面尺寸，改為中空獨立矩形浴缸外形；高度暫定。沒有把圖中未校正的尺寸偷偷改成標準浴缸尺寸。
- 三組玻璃隔間候選：固定玻璃、滑動門片、側框、上下軌、把手與淋浴五金。滑門採重疊開啟的原型，並非從照片確認開法。2D 使用虛線標示提案。
- 鏡面使用 Three.js r160 Reflector 實際反射模型；只在鏡面所在浴室的室內視角啟用，鳥瞰時停用反射以降低負擔。反射不含原照片人物、窗外展示板或電視畫面。
- 配色／隔間狀態隨家具方案 JSON 匯出及保存。V2.3 使用獨立本機儲存鍵，不覆蓋既有 V1/V2 狀態；舊家具方案可經原匯入功能另行導入。

另外移除了上一版疊在可移動電視櫃上的第二座固定櫃體。公共區地磚、既有牆柱／門窗與 28 個家具設備的平面數據沒有改動。原公共區天花目前仍是矩形燈槽原型，尚未細化為照片中的圓角。

## 來源與假設

外觀依據為對話附件 `2026-08-25.jpg`、`2026-08-25(2).jpg`、`2026-08-25(4).jpg`、`2026-08-25(16).jpg`。照片只支持外觀特徵，不支持本戶配色對應、尺寸、乾濕分界、排水點、五金型號或玻璃滑門施工。照片與 EXIF 未上傳 repo。

原幾何仍來自 `data/home.json`（IMG_6047／IMG_6049）。牆面區間引用原有牆、窗台／窗頂、門頭，不新增推測的牆。隔間深度來自草模中的可用空間，是試配而非實際使用淨寬認證；不相交也不代表使用間距合格。

層高延續 2800 mm；面盆頂 840 mm、浴櫃底 240 mm、鏡高 860 mm、玻璃高 2050 mm、浴缸高 590 mm 都是原型參數，並非照片量測。材質色彩未校色，燈光是視覺示意，不是照度或日照計算。

## 測試範圍

`node --test tests/*.test.mjs` 檢查原幾何與錨點不變、面材來源、開口、水平比例與垂直參數、隔間與既有設備平面不相交。

`scripts/smoke-bathrooms.mjs` 在 GitHub Actions 的 Chromium 中關閉網路，直接開啟完整離線 HTML；執行三間衛浴近景、配色切換、真實鏡面、隔間取消與滑門開關、保存、剖切、2D 引導線及無錯誤檢查，輸出實際 PNG 與 `verification.json`。工作流程存在不等於通過，請以當次結果為準。

仍待：實測比例／高度、衛浴配色與隔間實際位置確認、完整門扇掃掠及使用間距檢查、施工機電協調、臥室與公共區構件的進一步細化。
