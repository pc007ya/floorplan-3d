## 4. 逐區模型改造說明

### 4.1 客廳／餐廳／廚具：先做整體辨識度

**照片依據：P06、P07、P08；P11 只作另一組飾面／餐椅方案。**

廚具沿用 `island`、`hob`、`sink`、`cabinet` 的平面錨點。中島拆成頂面、兩側收邊、下櫃、門片／縫線及踢腳；白色外觀與灰米色櫃身分開指定材質，不整個模型只上一種顏色。爐具與水槽是獨立物件，換中島外殼不能讓它們消失、重複或偏離原定位。

原有 `cabinet` 目前使用通用 `wardrobe` 類型。下一版建立專用「廚具高櫃」原型，分出門板、層段、把手與電器面板，替換舊示意外觀而不是疊加第二座櫃子。照片可見並排嵌入式設備，但本戶是否配置同樣設備、型號與孔位均未定，不把照片設備型號寫成確定值。

P08 的 3 張高腳椅用於製作金屬色骨架、灰色坐墊與曲面椅背原型。**看到 3 張不等於本戶一定擺 3 張**；實際數量、前後退椅空間及是否保留通道，待校正尺度後檢查。吊掛式抽油煙機可建示意原型，排煙路徑、梁位及安裝高度不由照片推定。

客廳新增的配置候選為米灰布面感沙發、棕色外背單椅、深藍／灰黑石紋雙茶几及灰色地毯。電視牆使用 P07 的灰石紋外觀與深色懸浮櫃，下方燈帶獨立成組。電視所在牆面尚未確認，只在驗證不擋窗、不擋門、不占入口動線後指派牆面；不照抄照片的左／右方向。

餐桌建立白色頂面與深色椅框的原型；淺色椅墊版本另列為 P11 分支。餐桌與中島的高差、連接方法、用餐人數和尺寸尚未確定，不能由視角直接認定兩者是同高度的一體石材。

公共区天花初選 P06–P08 的圓角燈槽，與室內多邊形建立關係。白底深紋飾面與黑線條矩形天花不混入這個初選版本；保留為另一組可切換方案。

### 4.2 房間 a／b／c：先建原型，再定用途

**睡眠原型 S1（P02、P09、P14、P15）：**床架、床墊、枕頭、被套、床尾披巾與床頭牆分件。床頭牆再拆成面板、分縫、下段飾面與燈帶；P14 的上段深色飾面與 P02／P15 的下段深色床頭是不同組合，不能全部堆在一面牆。a 作優先試配；c 可選此原型，但雙人床／單人床尚未定。

**書桌床台原型 S2（P12）：**低床台、床墊、長檯面、桌下座位空間、下櫃、壁板與床下燈帶各自建模。b 作優先試配，並不表示它已確定是小孩房。工作檯面與床邊層板可做不同高度，不因照片透視看似連續就強制同高。

**開放收納原型 S3（P09、P10）：**側板、頂櫃、開放層板、吊衣桿、下方收納與層板燈分件。只在確定可用牆面後配置；不可因照片有更衣區，就把 `utility` 或 `outside-a` 改成更衣室。

各房窗簾使用既有窗洞作位置依據；布簾與紗簾獨立，不將照片內的大面展示景觀擅自轉換成落地窗。鏡面只反映模型中的環境，不貼上照片裡的人物倒影。

### 4.3 三套衛浴：兩種材質，保留既有設備錨點

**暖米款 B1（P01、P03、P13）：**米色橫向石紋牆磚、深灰石紋地面、白色設備、淺木紋浴櫃、銀色五金。`wet-a` 的浴缸保留位置，外形候選參考 P13 的獨立矩形浴缸；面盆候選參考 P01 的突出式方盆＋側邊檯面。外形可先製作，但不宣稱是原有設備的實際尺寸或安裝方式。

**冷灰款 B2（P05）：**灰色石紋牆地、白色方盆、淺木紋懸浮櫃、透明淋浴玻璃與銀色框件。此處 B2 是材質方案代碼，與建築戶別無關。

`wet-b` 與 `wet-c` 保留 `wc-b`／`basin-b` 及 `wc-c`／`basin-c`，材質款式先不指定。P03 的馬桶與 P05 可見的水箱式馬桶外形有差異，僅作設備原型選項，不據此判斷哪張是本戶哪一間。

淋浴隔間需分玻璃、邊框、固定件、門扇及把手，與浴室入口門分開。玻璃門的開法、乾濕分界與淋浴設備位置由本戶圖面補核後放置；照片不足以證明原圖所有衛浴都有同樣隔間。玻璃不可堵住馬桶使用區或門扇開啟區。

牆面材質按房間內側指定，不把衛浴的米色或灰色磁磚同時套到牆另一面的臥室。鏡面、面盆、龍頭和櫃身是獨立模型；不能以一張完整浴室照片貼在平面上替代 3D。

### 4.4 入口、未明區域與外側範圍

`entry` 可延伸公共區的淺色飾面與深色細邊，櫃體不是必加項目。出入口位置、門扇開向與通行範圍保持 V1。`utility`、`outside-a`、`outside-b` 不放入猜測的床、衣櫃、洗衣設備、陽台椅或外牆；待有本戶依據再處理。

## 5. 分層方式：把格局與室內裝修分開

以下為待實作的邏輯結構，不表示 repo 已新增這些程式模組：

```text
HomeModel
├── BaseArchitecture       # V1 牆柱、地面、門窗與既有設備錨點
├── InteriorFinishes       # 牆面內側飾面、地坪視覺方案
├── FixedJoinery           # 中島、高櫃、浴櫃、床頭板、書桌／收納
├── FurnitureLayout        # 沙發、餐椅、床、茶几；獨立的提案配置
├── CeilingAndLighting     # 燈槽本體、嵌燈、燈帶、照明來源
└── CurtainsAndAccessories # 布簾、紗簾、地毯、少量無品牌陳設
```

資料流仍以 `data/home.json → compileHome → 引擎` 為基礎。新增的 `data/proposals/showhouse-v2.json` **只是一份規劃資料，不是可直接匯入的家具方案，也不是已接上引擎的開關**。其中 `runtimeEnabled: false` 是規劃狀態標記，目前沒有程式讀取它。

下一輪可新增 `js/interior-overlay.mjs` 及建模函式，透過經過測試的轉接點加入原引擎；路徑目前僅為提議。`engine.html` 的固定 SHA 不隨意改寫，避免破壞既有編譯檢查。已有幾何繼續使用原資料；新裝修物件引用 roomId／fixtureId，不複製另一套房間多邊形。

### 座標、尺度與狀態

原 `home.json` 平面座標是描圖單位，必須經 `mmPerTraceUnit` 轉成 mm，再映射到 Three.js 的 X／Z；垂直方向是 Y。角度與門扇方向向量不能乘比例。新物件位置尚未確定時用 `null`，不可填 0 代表「不知道」而把物件放到原點。

延續既有暫定高度：層高 2800 mm、門頭 2100 mm、窗台 900 mm、窗頭 2400 mm。這些是 V1 示意值，不是從樣品屋照片量出。新櫃高、桌高、床高、天花下吊與燈槽斷面在本規劃不填假精度；原型試作採用的尺寸也必須標成暫定，不能藉縮放房間來容納它們。

每個新物件應分開記錄「外觀來源」與「放置依據」：照片可支持外觀，但不支持在本戶某面牆的位置。既有設備替換保留原 id 與平面錨點；替換與回復時只能有一個有效實例。

### 顯示、編輯與資料保存

鳥瞰／剖切時隱藏會遮住室內的天花本體，且牆面飾板遵守同一剖切狀態；室內視角才顯示完整天花。燈带的可見發光外觀與真正照亮模型的光源分開，並同步日夜控制；不聲稱具備實測照度或本戶日照模擬。

2D 與 3D 共用新家具的占地、位置及旋轉；拖移後平面不能留在舊位置。衣櫃開啟區、餐椅後退區、床邊通道與出入口另作干涉檢查。尺度未校正時只能說「草模中未相交」，不能說「實際走道合格」。

V1 的本機儲存鍵目前是模型 id＋比例＋高度。V2 應另存方案版本，不覆寫使用者已移動的家具、材質或測量資料；採明示切換與匯出備份。照片參考風格與現有地磚方案須能分別預覽、關閉與回復。

離線單檔交付也要包含新增的程式與所需材質；不能只讓 CDN 版本成功。原照片、人物、鏡中人影、商品商標、電視畫面、地址及 EXIF 不加入公開 repo 或模型。窗外採中性示意背景，不將樣品屋展示景觀當成本戶景色或座向。

## 7. 尚待確認，但不阻止原型製作的項目

優先補核一個可定位的實際長度與層高，再確認房間 A／B／C 用途、每間衛浴的材質款、地磚表面偏好，以及客廳電視牆與用餐人數。櫃體立面、門窗高度、梁位與排煙資料需另依圖面或現場；本文件不把未知內容偽装成已確認規格。

可先製作材質與櫃體原型，不必等待所有尺寸到齊；正式配置到戶型時，仍逐一保留「提案／待確認」標籤。
